## [0.1.0] - 2026-01-23

Initial release.

### Features

- Novus compiler with C backend targeting AmigaOS 68k
- Standard library with collections, strings, memory management
- Borrow checker for memory safety
- Inline assembly support
- AmigaOS FFI bindings (Exec, DOS, Graphics, Intuition, etc.)
- Test framework with `@test` attribute
- Programmer's guide (LaTeX/PDF)
- Website at novuslang.com
