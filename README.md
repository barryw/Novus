# Novus Programming Language

**A modern systems programming language for the Amiga 68k family of computers**

> *"New code for classic machines"*

## Overview

Novus is a compiled systems programming language designed specifically for the Amiga platform. It combines modern language features with direct hardware access and the efficiency required for 68k systems, while maintaining the authentic feel of Amiga development.

## Status

## Quick Start

### Prerequisites

- .NET 9.0 SDK
- VBCC toolchain
- Amiga NDK 3.9

### Build the Compiler

```bash
dotnet build
```

### Compile a Novus Program

```bash
dotnet run --project Novus/Novus.csproj -- examples/hello.novus -o hello
```

### Run Tests

```bash
dotnet test
```

## Example Code

### Hello World (Returns 42)

```novus
// Simple Novus program
fn main() -> u32 {
    return 42
}
```

### Arithmetic

```novus
fn calculate() -> u32 {
    return (10 + 20) * 2  // Returns 60
}
```

### Function with Parameters

```novus
fn add(a: i32, b: i32) -> i32 {
    return a + b
}
```

## Generated Assembly

Novus compiles to clean, readable 68k assembly:

```asm
; Generated by Novus compiler
; Target: Motorola 68000

section	text,code

xdef	_main
_main:
	moveq	#42,d0
	rts
```

## Key Features

### Currently Implemented ✅

- **C-like syntax** with modern ergonomics
- **Strong typing** with type inference
- **Integer types**: u8, u16, u32, u64, i8, i16, i32, i64
- **Arithmetic operations**: +, -, *, /,  %
- **CPU-target aware** code generation (68000-68060)
- **Optimization pipeline** with 6 passes (constant folding, DCE, CSE, etc.)
- **4 optimization levels** (-O 0 through -O 3)
- **moveq optimization** for small constants
- **Signed/unsigned** operation distinction
- **Amiga ABI compliance** (return values in d0)
- **VBCC integration** for assembly and linking
- **Comprehensive test suite** (93 tests, 100% passing)

### Planned Features 🔄

- Control flow (if/else, loops, match)
- Function calls and local variables
- Result/Option types for error handling
- Async/await (stackless coroutines)
- Structs and enums
- Pattern matching
- Pointers and arrays
- AmigaOS library integration
- Hardware DSLs (Copper, Blitter, Paula)
- Graphics asset DSLs (sprites, BOBs, bitmaps)

## Command-Line Options

```bash
dotnet run --project Novus/Novus.csproj -- <input.novus> [options]

Options:
  -o <file>          Output file name (default: a.out)
  --cpu <target>     Target CPU: 68000, 68020, 68030, 68040, 68060 (default: 68000)
  --emit-asm         Emit assembly only, don't assemble/link
  --emit-ir          Emit IR (intermediate representation)
  -v, --verbose      Verbose output
  --vbcc-path <path> Path to VBCC installation
  --ndk-path <path>  Path to Amiga NDK
  -O <level>         Optimization level (0-3)
```

## Design Philosophy

1. **Explicit over implicit** — No hidden allocations or magic
2. **Predictable performance** — Deterministic execution
3. **Readable syntax** — Code should be obvious
4. **Respect the machine** — Leverage Amiga hardware, don't hide it
5. **Amiga first** — Not cross-platform; focused on authentic Amiga development

## CPU Targets

Novus supports multiple 68k CPU targets:

| Target | Features |
|--------|----------|
| 68000 | Base instruction set, 16-bit multiply/divide |
| 68010 | Same as 68000 with minor improvements |
| 68020 | 32-bit multiply/divide, barrel shifter, more addressing modes |
| 68030 | MMU, 68020 superset |
| 68040 | FPU, pipeline optimizations |
| 68060 | Superscalar, advanced pipeline |

The compiler automatically selects appropriate instructions for each target.
